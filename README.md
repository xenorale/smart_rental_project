# Ближе

Прототип поиска долгосрочной аренды в Воронеже. Указываешь, куда нужно добираться, сколько минут готов тратить и какой у тебя бюджет. На карте появляется общая зона, а рядом видны подходящие квартиры со временем до каждой точки

## Запуск на Windows

Понадобятся Python 3.13, Node.js 22 и [Ollama](https://ollama.com/download). Дважды кликни по `start.cmd`. Первый запуск соберёт сайт, установит зависимости и скачает модель примерно на 1 ГБ в `.local/ollama`

Сайт откроется на [127.0.0.1:8787](http://127.0.0.1:8787). Без Ollama можно пользоваться поиском, картой и исходными отзывами

Для запуска вручную:

```powershell
npm ci
npm run build
python -m pip install -r requirements.txt
python -m uvicorn server.main:app --host 127.0.0.1 --port 8787
```

Если Ollama уже работает на порту 11434, можно задать `RENTAL_OLLAMA_URL=http://127.0.0.1:11434` перед запуском API и выполнить `ollama pull qwen2.5:1.5b`

## Что можно попробовать

- Выбрать место из подсказок или поставить свою точку на карте. Для каждой точки есть лимит времени и способы добраться пешком или на машине
- Изменить бюджет, количество комнат, порядок сортировки и сохранить понравившиеся варианты в браузере
- Открыть карточку и запросить сводку отзывов. Qwen2.5 1.5B работает локально на CPU, использует до четырёх потоков и выгружается после ответа. API проверяет, что цитаты есть в исходных отзывах
- Посмотреть несколько объявлений одной квартиры. Демо-импорт группирует варианты с одинаковыми параметрами объекта и фотографией. Цена может различаться

Объявления, цены и отзывы демонстрационные. Время считается по дорожному графу с фиксированными скоростями и учётом направления. Общественный транспорт, пробки и ограничения поворотов пока за рамками прототипа. Заливка на карте приближённая, условия поиска проверяются по расчётному времени до каждой точки

## Код и проверка

React и Leaflet отвечают за экран и карту. FastAPI считает маршруты и доставляет данные. Карта, граф и каталог лежат рядом с кодом, избранное хранится в браузере

```powershell
python -m unittest discover -s tests -p 'test_*.py'
npm test
```

Для браузерных тестов запусти собранный сайт. Playwright на Windows использует установленный Chrome, на другой машине можно установить Chromium через `npx playwright install chromium`
