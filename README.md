# Ближе

Прототип поиска долгосрочной аренды в Воронеже. Выбираешь район, цену и параметры квартиры. Если важно время в дороге, добавляешь точки и задаёшь лимит для каждой

## Запуск на Windows

Понадобятся Python 3.13, Node.js 22 и [Ollama](https://ollama.com/download). Дважды кликни по `start.cmd`. Первый запуск соберёт сайт, установит зависимости и скачает модель примерно на 1 ГБ в `.local/ollama`

Сайт откроется на [127.0.0.1:8787](http://127.0.0.1:8787). Без Ollama доступны поиск, карта и исходные отзывы

## Что можно попробовать

- Выбрать несколько вариантов по комнатам, например студию и однокомнатную. Фильтры обновляют выдачу автоматически
- Задать район или приблизить карту и нажать «Искать в этой области». В «Фильтрах» есть площадь, этаж, исключение первого и последнего этажей и вариант без комиссии
- Добавить до трёх точек из адресного поиска или поставить их вручную. Для каждой точки можно выбрать пеший или автомобильный маршрут и свой лимит
- Нажать «Попробовать пример». В демо до Кольцовской, 24 максимум 20 минут на машине и до Галереи Чижова максимум 5 минут пешком проходит квартира на Кольцовской, 35А. Если заменить Галерею на ТРК «Арена», демо-выдача пустая
- Открыть карточку и переключать «Квартира», «Дом» и «Район». Для каждой вкладки есть характеристики и свои демонстрационные отзывы. На вкладке района есть ближайшие остановка, магазин и парк из OpenStreetMap, если они найдены. Сводка использует цитаты из отзывов

Объявления, цены и отзывы демонстрационные. Демо-импорт группирует объявления одного объекта и показывает исходные цены. Избранное хранится в браузере

## Маршруты

По умолчанию время вычисляется из квартиры до каждой точки по OpenStreetMap. Граф учитывает направление улиц и использует фиксированные скорости. В карточке можно открыть маршрут в Яндекс Картах и посмотреть, что они показывают сейчас

Чтобы API учитывал пробки при отборе квартир, нужен ключ [Матрицы расстояний Яндекса](https://yandex.ru/maps-api/docs/distancematrix-api/index.html). Ключ берётся из переменной `RENTAL_YANDEX_KEY` на сервере. Пример запуска отдельного экземпляра из PowerShell 7, если на 8787 уже работает демо:

```powershell
$env:RENTAL_YANDEX_KEY = Read-Host 'Ключ Яндекс Карт' -MaskInput
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8788
```

В этом режиме Яндекс рассчитывает время для автомобильных поездок на момент запроса. Ответ переиспользуется в пределах 45-секундного окна, чтобы переключение обычных фильтров не тратило лишние запросы. Пешие маршруты и приближённая зона на карте по-прежнему считаются по OpenStreetMap. При ошибке сервиса выдача возвращается к локальному расчёту и сообщает об этом

## Код и проверка

React и Leaflet отвечают за экран и карту. FastAPI считает маршруты и доставляет данные. Qwen2.5 1.5B работает локально на CPU с четырьмя потоками и выгружается после ответа

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py'
npm test
```

Для браузерных тестов запусти собранный сайт. Playwright на Windows использует установленный Chrome. Чтобы прогнать запрос к локальной модели, выставь `RENTAL_TEST_MODEL=1`

## Данные

- Карта, дорожный граф и адресный индекс содержат данные [OpenStreetMap](https://www.openstreetmap.org/copyright) под ODbL 1.0.
